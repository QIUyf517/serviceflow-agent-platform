# ServiceFlow 演示商品信息说明

> 来源：ServiceFlow 项目自编演示文档。版本：1.0.0。本文不描述任何真实厂商商品规格、价格、库存或售后承诺。

## 商品与变体标识

演示数据把商品和具体变体分开标识。商品标识用于查询商品集合，商品项标识用于指向订单中的具体变体。实际名称、选项、价格与可用性只能从当前业务数据库读取，不能从本文推断。

## 退货数量表达

演示 API 使用 `item_quantities=商品项标识:数量` 的显式格式，例如单个商品项数量为一时写作 `item_quantities=item_demo:1`。服务端会对照订单中的真实商品项和数量重新校验；文档示例本身不证明该商品存在。

## 退款途径说明

退款途径标识必须来自已核验用户的当前账户数据，并通过固定版本硬规则校验。ServiceFlow 演示系统只登记退货申请，不连接真实支付网络，不承诺退款到账时间。

## 数据来源边界

向量索引仅包含固定业务规则和这些静态演示说明，不包含用户身份、订单、支付记录或其他实时业务事实。实时事实始终由业务数据库按授权读取。
